# Codewhale

Codewhale is an open-source coding agent. It runs in your terminal, works with
the model provider you choose, and keeps approvals and receipts in your hands.

- **Website:** https://codewhale.net
- **Install:** `npm install -g codewhale` — other options are in the
  [install guide](https://github.com/codewhale-hq/Codewhale/blob/main/docs/INSTALL.md)
- **Questions and ideas:** [Discussions](https://github.com/codewhale-hq/Codewhale/discussions)
- **Security reports:** [private advisory form](https://github.com/codewhale-hq/Codewhale/security/advisories/new)

## Repositories

| Repository | What it is |
| --- | --- |
| [Codewhale](https://github.com/codewhale-hq/Codewhale) | The agent: Rust engine, terminal UI, CLI, docs and website source |
| [codewhale-plugin-marketplace](https://github.com/codewhale-hq/codewhale-plugin-marketplace) | First-party plugins and skills |
| [codewhale-cu-plugin](https://github.com/codewhale-hq/codewhale-cu-plugin) | Computer Use for macOS |
| [codewhale-ratatui](https://github.com/codewhale-hq/codewhale-ratatui) | Reusable terminal UI components from Codewhale |

## Contributing

Issues and pull requests are welcome. Start with the
[contributing guide](https://github.com/codewhale-hq/Codewhale/blob/main/CONTRIBUTING.md)
and the pinned issue in the main repository. Contributor pull requests merge
